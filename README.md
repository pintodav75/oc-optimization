# oc-optimization — OpenClassrooms Project 4

Improve the performance and SEO of an existing agency website ("La Chouette
Agence") without changing what it looks like.

**Stack:** HTML, CSS, vanilla JS · **Context:** OpenClassrooms Web Developer path

## What was done

- **Images:** converted to WebP and correctly sized; the largest payload on the
  page dropped sharply.
- **Loading:** render-blocking resources deferred, offscreen images loaded lazily.
- **Markup & SEO:** semantic tags, meaningful `alt` text, single `h1`, descriptive
  `<title>` and meta description.
- **Accessibility:** heading order and colour contrast checked.

## Deliverables

- `index.html`, `contact.html` — the optimised site
- `audit/` — the before/after SEO & performance audit (spreadsheet)

## Run

Open `index.html` in a browser — it is a static site.
